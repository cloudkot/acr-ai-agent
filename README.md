# ACR AI Agent

Интеллектуальный агент для Академии цифрового развития (АЦР). Собирает образовательные программы (ДПО и общеразвивающие), проверяет математику часов и генерирует полный комплект материалов: тесты, семинары, лекции, слайды, рабочие программы и библиографию.

## Запуск проекта

### Быстрый запуск на ВМ
Для автоматизации развертывания используется скрипт:
```bash
cd ~/project
chmod +x start.sh
./start.sh
Скрипт обновляет код, пересобирает фронтенд, применяет миграции базы данных и запускает сервер на порту 8000.

Запуск через Docker
Сборка использует multi-stage подход (React собирается через npm ci, затем переносится в легкий Python-образ). Контейнер работает от non-root пользователя и имеет HEALTHCHECK.

bash
docker-compose up --build -d
Локальный запуск
Бэкенд:

bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
Фронтенд:

bash
cd frontend
npm install
npm run build
Бэкенд автоматически раздает статику фронтенда.

Архитектура и гранулярная генерация
В основе проекта лежит паттерн GigaCowork. Вместо жесткого скрипта используются независимые навыки (Skills), управляемые оркестратором (orchestrator.py), которые наследуются от базового класса BaseAgent:

CurriculumSkill — генерация каркаса и распределение часов.

ContentSkill — генерация контента.

RevisionSkill — точечные правки каркаса.

Для работы с большими программами (до 500 часов) применяется гранулярная генерация и асинхронность. Оркестратор разбивает задачи на мелкие порции (например, по 5 вопросов или по 3 модуля) и отправляет их параллельно через AsyncOpenAI и asyncio.gather. Лимит вывода для каждого запроса установлен в 10 000 токенов. Это решает проблему таймаутов и обрезки JSON на больших объемах данных.

Валидация и защита от галлюцинаций
Агент строго контролирует сгенерированный контент:

Математика часов: Валидатор проверяет два уровня: ЛК + ПР + ЛБ + СРС = Всего внутри модуля и Сумма модулей + Аттестация = Общий объем. При ошибках LLM срабатывает auto_correct_hours для пропорционального пересчета.

Программные ограничения: Функция enforce_content_constraints принудительно проверяет скрытые требования кейса (например, автоматически фильтрует слайды, оставляя только модуль pandas, или гарантирует генерацию минимум 20 вопросов для 500-часовой программы).

Анти-галлюцинации: Код проверяет библиографию на наличие запрещенных сервисов (ChatGPT, Midjourney) и заменяет их на GigaChat. Если у источника нет года выпуска, ставится тег [НЕПОДТВЕРЖДЕННЫЙ ИСТОЧНИК].

Безопасность ввода: В schemas.py реализован санитайзер, который очищает входящие данные от XML-тегов и паттернов Prompt Injection.

ML-склейка (Smart Fallback)
Если нейросеть на больших объемах не справляется с генерацией семинара для конкретного модуля, срабатывает алгоритмический fallback (_generate_smart_fallback_seminar). Он не подставляет шаблонный текст, а анализирует поле related_topics в каркасе программы, находит компетенции, привязанные к этому модулю, и алгоритмически формирует осмысленное практическое задание на их основе.

Тестирование
Покрыты критически важные сценарии: сквозной пайплайн, математика часов, обработка ловушек (DevOps 256ч, pandas) и умная склейка.

bash
cd backend

Соответствие требованиям кейса
Требование	Реализация
Поддержка 2 шаблонов АЦР	Автовыбор в orchestrator.py (ДПО / Общеразвивающая)
Карта компетенций (ЗУН)	schemas.py + связь с модулями через related_topics
Учебный план с проверкой часов	validator.py (детализация по ЛК/ПР/ЛБ/СРС + автокоррекция)
Генерация контента	Параллельная гранулярная генерация тестов, семинаров, лекций и программ
Human-in-the-loop	Эндпоинты /api/generate и /api/approve (без утверждения контент не генерируется)
Прием референсов	.docx, .txt, .pdf (защита от Path Traversal, лимит 5 МБ)
Уточняющие вопросы	При отсутствии часов возвращается статус clarification_needed
Экспорт	Word, PowerPoint, LMS (GIFT), Moodle XML и полный JSON (export.py)
