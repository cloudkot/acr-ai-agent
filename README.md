# ACR AI Agent

ИИ-агент для Академии цифрового развития. Методист описывает задачу,
прикладывает референсы, а агент собирает программу обучения и весь
комплект материалов: карту компетенций, учебный план с часами, тесты,
задания для семинаров, планы лекций и слайды.

Работает с двумя шаблонами АЦР — повышение квалификации и
общеразвивающая программа. Поддерживает любое ИТ-направление и объём
от 16 до 500 часов.

## Статус

Сейчас идёт этап проектирования и подготовки каркаса. Спроектирована
мультиагентная архитектура, настроен репозиторий, определён стек.

Полноценный запуск backend начнётся после выдачи доступа к Cloud.ru —
без ключей вызовы моделей и RAG невозможны.

## Из чего состоит

- `backend/` — FastAPI-сервис, оркестратор и агенты
- `frontend/` — React-интерфейс для методиста
- `.env.example` — шаблон переменных окружения
- `README.md` — этот файл

## Стек

Backend на Python и FastAPI, обращение к Cloud.ru через
OpenAI-совместимый SDK.

Frontend на React, Vite и TypeScript.

Запланированные модели: GigaChat 3.5 Ultra и Reasoning, Qwen3,
DeepSeek V4. Поиск по источникам через Managed RAG, векторную базу,
эмбеддинги Qwen3 и реранкер.

Экспорт документов через python-docx и python-pptx. Хранение
артефактов в Object Storage, состояние сессии — в JSON.

## Как запустить

Backend пока в виде каркаса, эндпоинты описаны в `backend/main.py`.

Frontend:

    cd frontend
    npm install
    npm run dev

Откроется на http://localhost:5173.
