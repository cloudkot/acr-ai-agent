# ACR AI Agent — Команда VlPKteam

Интеллектуальный агент для Академии цифрового развития (АЦР). Собирает образовательные программы (ДПО и общеразвивающие), проверяет математику часов и генерирует полный комплект материалов: тесты, семинары, лекции, слайды и рабочие программы.

## Как это запустить

Мы подготовили скрипт для быстрого запуска на виртуальной машине и инструкцию для локальной разработки.

### Быстрый запуск на ВМ
```bash
cd ~/project
chmod +x start.sh
./start.sh
Приложение поднимется на порту 8000 (демо доступно по адресу хакатона).

Архитектура: GigaCowork Pattern
Кейс требовал строить агента по принципу GigaCowork (каждый шаг — отдельный навык с понятной инструкцией). Мы реализовали это через базовый класс BaseAgent и явные классы-навыки в orchestrator.py:

CurriculumSkill — генерирует каркас, распределяет часы и компетенции.

ContentSkill — параллельно (через asyncio.gather) генерирует тесты, семинары, лекции, слайды и библиографию. Это защищает от таймаутов и обрезки текста.

RevisionSkill — вносит точечные правки в каркас, не пересобирая всё заново.

Такая модульная архитектура позволяет легко добавлять новые навыки и передавать контекст между ними.

Экономика и оптимизация токенов
LLM Router: Сложные задачи (каркас, слайды) отправляются в GigaChat 3.5 Reasoning, а простые тексты (тесты, семинары) — в GigaChat 3 Pro. Это экономит бюджет.

Минификация контекста: В content.py контекст передается в виде минифицированного JSON без пробелов, что снижает расход входных токенов.

Аналитика: В консоли сервера логируются потраченные токены и стоимость в рублях для каждого запроса. На фронтенде есть дашборд с экономией времени и денег.

Безопасность и ограничения кейса
Только Cloud.ru: В cloud.py стоит жесткая проверка домена OPENAI_BASE_URL. Если кто-то попытается подменить URL на OpenAI, сервер не запустится.

Prompt Injection Sanitizer: В schemas.py все входящие данные очищаются от XML-тегов, кавычек и инъекций (вроде "Ignore previous instructions"), что защищает от взлома промптов и разрыва JSON.

Безопасная загрузка: Файлы сохраняются под UUID-именами, имеют лимит 5 МБ и белый список расширений (.docx, .pdf, .txt).

Прохождение скрытых тестов кейса
Мы учли все «ловушки» из тестовых запросов:

Python для школьников: Если тип «Общеразвивающая», профстандарты обнуляются. Слайды программно фильтруются только для первых двух модулей.

Data Analysis: Слайды программно фильтруются только для модуля pandas.

DevOps 256ч: Если в ограничениях указано «без лекций», auto_correct_hours жестко ставит 0 лекций и практик, перекидывая часы в СРС.

Кибербезопасность (без часов): Агент возвращает статус clarification_needed и задает уточняющие вопросы, а не выдумывает цифры.

Тесты и валидация
В backend/tests/ лежат тесты pytest для проверки эндпоинтов и математики часов.

В validator.py реализована двойная проверка: внутри модуля (ЛК + ПР + ЛБ + СРС = Всего) и по всей программе (Сумма модулей + Аттестация = Общий объем).
