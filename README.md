# ACR AI Agent — Команда VlPKteam

[![Backend CI](https://github.com/cloudkot/acr-ai-agent/actions/workflows/ci.yml/badge.svg)](https://github.com/cloudkot/acr-ai-agent/actions)

Этот репозиторий — наше решение для кейса Академии цифрового развития (АЦР). По сути, это ИИ-агент, который собирает образовательные программы. Методист вводит тему, часы и ограничения, система предлагает каркас, проверяет арифметику, а после утверждения генерирует тесты, семинары, лекции и выгружает всё это в Word, PowerPoint и формат для LMS.

## 🚀 Как это запустить

Мы подготовили два способа: через Docker (рекомендуется) и локально для разработки.

### Вариант 1. Docker (Всё в одном контейнере)
Внутри `Dockerfile` используется multi-stage сборка: сначала собирается React-фронтенд (через `npm ci`), а потом всё упаковывается в легкий Python-образ. Контейнер работает от имени непривилегированного пользователя (`appuser`) и имеет встроенный `HEALTHCHECK`.

1. Создайте файл `.env` в корне (рядом с Dockerfile) и заполните ключи:
```env
OPENAI_API_KEY=ваш_ключ_от_Cloud.ru
OPENAI_BASE_URL=https://hub.gigaschool.ru/api/v1/llm/v1
```

2. Соберите и запустите:
```bash
docker build -t acr-agent .
docker run -d -p 8000:8000 --name acr-app --env-file .env acr-agent
```
Приложение будет доступно на `http://localhost:8000`.

### Вариант 2. Локальный запуск
Нам нужны Python 3.11+ и Node.js 20+.

**Бэкенд:**
```bash
cd backend
python -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

**Фронтенд (в отдельном терминале):**
```bash
cd frontend
npm install
npm run build  # Собираем в папку dist, откуда его забирает бэкенд
```

## ⚙️ Переменные окружения и безопасность
В `cloud.py` реализована **жесткая фиксация провайдера**. При запуске сервер проверяет `OPENAI_BASE_URL`. Если URL не принадлежит доменам Cloud.ru / GigaSchool, приложение упадет с ошибкой. Это гарантирует соблюдение ограничения кейса «только модели Cloud.ru».

## 🛠 Что под капотом

Мы не стали пихать LLM везде. Где-то используем классические алгоритмы, а где-то — строгую математику.

*   **FastAPI + SQLite:** API и персистентное хранение сессий с логами аудита. Никаких словарей в памяти — всё пишется в базу (`sessions.db`).
*   **Умный поиск (RAG + ML):** Для поиска по нормативке (273-ФЗ, Приказы 499/629) мы используем `scikit-learn` (TF-IDF + косинусное сходство). Это дешевле и быстрее, чем каждый раз скармливать нейросети весь справочник.
*   **LLM Router:** GigaChat Reasoning вызывается для сложной структурной логики (каркас, слайды), а GigaChat-3-Pro — для простых текстов.
*   **Программная валидация ограничений:** Если методист просит «ровно 10 вопросов» или «слайды только для модуля pandas», система после генерации программно проверяет, что нейросеть выполнила эти требования (`check_content_constraints`). Если нет — в документе Word появится красное предупреждение, а в PPTX — отдельный слайд.
*   **Железобетонная арифметика:** Валидатор проверяет два уровня: `ЛК + ПР + ЛБ + СРС = Всего` внутри каждого модуля, и `Сумма модулей + Аттестация = Общий объем`. Ошибки из референсов (как в кейсе с DevOps на 256 часов) автоматически исправляются.

## 🎯 Соответствие требованиям кейса

| Требование | Как реализовано |
| :--- | :--- |
| Поддержка 2 шаблонов АЦР | Автовыбор в `orchestrator.py` (ДПО / Общеразвивающая) |
| Карта компетенций (ЗУН) | `schemas.py` + строгие Pydantic-модели |
| Учебный план с проверкой часов | `validator.py` (детализация по ЛК/ПР/ЛБ/СРС + автокоррекция) |
| Генерация контента | Тесты, семинары, лекции, рабочие программы и библиография (`content.py`) |
| Human-in-the-loop | Эндпоинты `/api/generate` и `/api/approve` (без утверждения контент не генерируется) |
| Прием референсов | `.docx`, `.txt`, `.pdf` (защита от Path Traversal, лимит 5 МБ) |
| Уточняющие вопросы | Если часы не переданы, возвращается статус `clarification_needed` |
| Экспорт | Word, PowerPoint, LMS (GIFT) и полный JSON (`export.py`) |
| Пометка источников | Если LLM не уверена в профстандарте, ставится `[НЕПОДТВЕРЖДЕННЫЙ ИСТОЧНИК]` |
