# ACR AI Agent

ИИ-агент для Академии цифрового развития. Методист описывает задачу,
прикладывает референсы, а агент собирает программу обучения и весь
комплект материалов: карту компетенций, учебный план с часами, тесты,
задания для семинаров, планы лекций и слайды.

Работает с двумя шаблонами АЦР (повышение квалификации и общеразвивающая
программа), с любым ИТ-направлением и объёмом от 16 до 500 часов.

## Статус

Сейчас идёт этап проектирования и подготовки каркаса. Спроектирована
мультиагентная архитектура, настроен репозиторий, определён стек.
Реализация начнётся после выдачи ключей Cloud.ru.
