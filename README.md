# ACR AI Agent

Интеллектуальный агент для Академии цифрового развития (АЦР). Собирает образовательные программы (ДПО и общеразвивающие), проверяет математику часов и генерирует полный комплект материалов: тесты, семинары, лекции, слайды, рабочие программы и библиографию.

## Запуск проекта

### Быстрый запуск на ВМ
Для автоматизации развертывания используется скрипт `start.sh`:
```bash
cd ~/project
chmod +x start.sh
./start.sh
Скрипт обновляет код, пересобирает фронтенд, применяет миграции базы данных и запускает сервер на порту 8000.

Запуск через Docker
Сборка использует multi-stage подход. Контейнер работает от non-root пользователя и имеет HEALTHCHECK.

bash
docker-compose up --build -d
Локальный запуск
Бэкенд:

bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
Фронтенд:

bash
cd frontend
npm install
npm run build
Архитектура и гранулярная генерация
В основе проекта лежит паттерн GigaCowork. Вместо жесткого скрипта используются независимые навыки (Skills), управляемые оркестратором (orchestrator.py), которые наследуются от базового класса BaseAgent:

CurriculumSkill — генерация каркаса и распределение часов.

TestsSkill, LecturesSkill, SeminarsSkill и др. — изолированные генераторы контента.

RevisionSkill — точечные правки каркаса.

ValidationSkill — проверка математики и ограничений.

Для работы с большими программами (до 500 часов) применяется гранулярная генерация и асинхронность. Оркестратор разбивает задачи на мелкие порции и отправляет их параллельно через AsyncOpenAI и asyncio.gather. Это решает проблему таймаутов и обрезки JSON на больших объемах данных.

Прохождение скрытых тестов кейса (Ловушки)
Мы учли все нестандартные ситуации, описанные в кейсе, и реализовали их программную обработку:

Python для школьников (Общеразвивающая): В curriculum.py профстандарты принудительно обнуляются, если выбран этот тип. В validator.py срабатывает фильтр слайдов (только первые два модуля) и жестко задается генерация ровно 10 вопросов.

ИИ для учителей: В промптах curriculum.py стоит ограничение на использование только российских ИИ-сервисов (GigaChat, YandexGPT). Запрещенные сервисы блокируются.

Анализ данных (pandas): В validator.py реализована фильтрация слайдов. Если в названии модуля есть "pandas", остальные слайды отбрасываются.

Кибербезопасность (без часов): Если в запросе не указан объем, эндпоинт /api/generate возвращает статус clarification_needed с уточняющими вопросами, а не выдумывает цифры.

DevOps стажировка (256ч): В validator.py функция auto_correct_hours игнорирует математические ошибки из референса. Если указано "без лекций", она принудительно обнуляет лекции и практики, перекидывая все часы в СРС (254 часа) и оставляя 2 часа на аттестацию.

Валидация и защита от галлюцинаций
Агент строго контролирует сгенерированный контент:

Математика часов: Валидатор проверяет два уровня: ЛК + ПР + ЛБ + СРС = Всего внутри модуля и Сумма модулей + Аттестация = Общий объем. При ошибках LLM срабатывает автокоррекция.

Анти-галлюцинации: Код проверяет библиографию на наличие запрещенных сервисов и заменяет их. Если у источника нет года выпуска, ставится тег [НЕПОДТВЕРЖДЕННЫЙ ИСТОЧНИК].

Безопасность ввода: В schemas.py реализован санитайзер, который очищает входящие данные от XML-тегов и паттернов Prompt Injection.

Тестирование
Проект покрыт тестами pytest и pytest-asyncio. Тесты проверяют сквозной сценарий, работу валидатора и обработку скрытых ловушек (например, корректное обнуление лекций для DevOps или фильтрацию слайдов pandas).

bash
cd backend
pytest tests/
